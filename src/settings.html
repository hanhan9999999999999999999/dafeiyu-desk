Ctrl+Alt+S

没反应怎么办三条最常见的

  • 被别的软件占了：QQ、微信、录屏、显卡驱动都可能抢同一个组合，换一个就好。
  • 组合里至少要有一个修饰键（Ctrl / Alt / Shift），只有字母的键不收。
  • 以管理员身份运行的窗口收不到普通全局热键；需要的话把本程序也用管理员身份启动。

回复来源DSH 还是自定义 API

DSH 能看到你的文件、能动手干活；API 不依赖 DSH，换台电脑也能用。

走哪边DSH 有工具能力，API 更轻、更独立
接口地址OpenAI 兼容，填到 /v1 为止，例如 https://api.deepseek.com/v1
API Key本地模型（ollama / llama.cpp）不校验时可以留空
模型名例如 deepseek-chat / gpt-4o-mini / qwen-plus
