# 大肥鱼 1.5.0

发布日期：2026-11-15

这一版的关键词是「能自己好」。她以前出问题只能靠你看日志猜，
现在每一个环节都会自己检查、自己修，修不了就用人话说清楚是哪儿坏了。

---

## 下载

- 安装版：`大肥鱼-Setup-1.5.0.exe`（推荐，自动更新走这个）
- 免安装：`大肥鱼-1.5.0-portable.zip`

## 这一版新增了什么

### 1. 变声引擎有了真正的控制台

设置 → 声音与行为 → 变声引擎，最上面是「现在用的是哪个引擎」：

- 状态点（绿=在跑 / 黄=装好了没启动 / 红=环境不全）
- 就绪徽章 + 一句话活句（`引擎在跑 · cuda:0 · cute`）
- 四格事实：实际出声 / 运行设备 / 闲置释放 / 引擎目录
- **一键启动 · 关闭引擎 · 刷新**

引擎目录可以自己填、选文件夹、并且有「校验」——缺哪一项会逐条列出来。

### 2. 闲置自动释放显存（时长自己定）

默认闲置 10 分钟就把模型从显存里放掉（约 8GB），下次开口自动重装。
1–720 分钟随便填，不想要就关掉开关（常驻）。

### 3. 不骗你：回落会说出口

飞鱼没起来、XTTS 没装、显存不够——这些以前只写进日志，你听到的是 TTS
却以为飞鱼就这声音。现在她会自己说：「飞鱼还没起来——显卡挤不出显存，
这句先借内置的声音替我说。」同一种原因 5 分钟内只念一次。

### 4. 没有 DSH 也能用（桥接自愈）

- 先探你填的地址；不通就自己起一个随身桥接；只在当前是本机地址时把地址指过去。
- 每 90 秒巡一次，进程挂了自动按退避重拉。
- 设置 → 连接与模型 多了一行「一键自检并修复」。

### 5. 游戏模式

托盘 →「游戏模式（极致省性能）」。进去之后停渲染、停轮询、把 8GB 显存还回去，
窗口从任务栏和 Alt-Tab 消失，只剩托盘图标。三个方式退出：点托盘、
按一次唤出热键、或重启程序。

### 6. 一键体检 + 详细诊断报告

设置 → 概览 →「开始体检」，14 项检查，每项写清状态、证据、修法。
结果同时落一份 `诊断报告-<时间>.md` 到数据目录，里面还附了给接手的人/AI
看的定位说明。出问题不用再截图问我，把那份报告发出来就行。

### 7. 换任何模型都能对上表情动作

匹配改成打分制（标准名 / 别名 / 关键词 / 反向词扣分），
不会再出现「身体角度被当成转头」这种事。缺槽位时用替身并把替身标出来。
适配器右上角直接写「完全兼容 / 基本兼容 / 能用但少细节 / 只保证基础动作」，
并且明确告诉你缺哪几个、哪些是替身。

### 8. 适配器三步上手 + 两份说明书

窗口里多了可折叠的「怎么用（三步）」。
`docs/模型适配器-使用说明.md`（给人看）、`docs/模型适配器-AI交接说明.md`（给 AI 看）。

### 9. 表情和动作之间终于有过渡了

情绪一次算清，表情和动作共用同一个判断；动作按情绪加权挑，
并避开最近三段（以前会 A→B→A→B 横跳）；交接时长按「上一个动作演到哪儿」算，
快演完的短交接、刚起被打断的长一点，不会抽搐。

### 10. 闲置词扩到 621 句，还能按音色预合成

`idle` 45→107、`longIdle` 20→44、`ping` 16→31，新增工作/吃饭/天气三池。
设置 → 听与说 → 「她主动说话的时候」：按当前引擎+音色把 324 句预合成到本地，
触发时直接播缓存；「是否出声」「是否弹气泡」两个开关分开；
还能开「换完引擎或音色 8 秒后自动补」。

### 11. 语音链路提速

播放线程不再用 `sleep` 轮询，改成唤醒通知——每段少等最多 50ms，
CPU 也不空转了。音质一点没动。

---

## 升级注意

- 直接覆盖安装即可，设置与已导入的模型都会保留。
- 如果之前手动改过 `bridgeUrl` 指向**远端**机器，那一项不会被自动改写。
- 语音缓存目录在 `数据目录/idle-cache/`，换音色会新建子目录，旧的不会自动删。
