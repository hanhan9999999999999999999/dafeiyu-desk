# 大肥鱼 1.3.0

2026-11-14 · Windows 10 / 11 x64 · 930,192,268（约 887.1 MB）

这一版把「陪伴」补完整了：相处档案、等级与徽章、托盘快捷投喂与摸头，少点两次就能逗她；
同时修掉一批会让人出戏的小毛病，补上键盘与读屏支持。

## 新增

- **相处档案**：右键菜单或托盘打开。今天吃了什么、玩了多久、摸了几次，最近七天的柱状图，
  10 枚徽章与 8 级关系一眼看完；可以复制成文字，或导出 `.md`。
- **关系与徽章**：升级、解锁徽章她会在气泡里说一声，不再悄悄发生。
- **快捷互动**：托盘和右键菜单里的「喂她一口」（小鱼干 / 布丁 / 热可可 / 月亮糕）与「摸摸头」，
  她会在主窗气泡里回应；刚吃过、正在忙、在睡觉都会说明原因。
- **静音与音量**：托盘、设置、`Ctrl+Shift+M` 三处同步，音量 0–100%。
- **设置中心搜索**：输入关键词直接跳到对应设置项；Ctrl/⌘+F 聚焦搜索，回车把焦点送到第一个命中控件。
- **检查更新**：设置 → 关于里手动检查 GitHub Releases，有新版会告诉你并打开下载页。
- **对话记录导出**、输入历史、托盘「暂停动效」。
- **键盘与读屏**：养成面板可用 Tab 走遍、Enter / 空格开始或停止，灰卡会把原因念给读屏；
  气泡是 live region，她的回复会被读屏念出来；设置、对话记录、看屏幕、首次引导的焦点环都补齐了。

## 修复

- 帧率读数改为真实值，不再长期显示 60。
- 隐藏、最小化、锁屏、休眠多个来源都会暂停渲染，恢复时按原状态回来。
- 相处档案 480×706 不再溢出，标题栏可拖、Esc 可关。
- 养成面板重复结算、旧状态覆盖新状态、关闭时活动收尾无声。
- 首次启动不再因为「还没选模型」在控制台打一条 404。
- 安装包不再夹带开发机的 `debug.log`。
- **安装包瘦身 44%**：`site-packages` 里随依赖一起进来的 Python 测试夹具
  （`onnx/backend/test/data` 一处就 5525 个文件）不再被打进安装包，安装文件数从
  12810 降到 7168，包体 896.6 MB → 887.1 MB。文件数才是安装与卸载耗时的大头，
  覆盖安装因此明显变快；最长路径也从 203 字符降到 135 字符，装到很深的目录里
  不会再撞 Windows 的 260 字符上限。
- 桥接与看屏幕只接受 `http(s)` 地址；手改配置里的字符串类型会被纠正而不是崩溃。
- 相处档案的「复制 / 导出」改走主进程剪贴板与系统对话框，透明、置顶窗口下也能用。
- 输入条换成深色底，白裙背景上也看得清。
- 搜索框里按 Esc 只清空搜索，不再顺手把整扇设置窗关掉。
- **设置里「参考音频目录」那个框以前存不上**：只有旁边的「选文件夹」按钮会写它，用键盘改完按回车、
  或者点别处，什么都不会发生，框在那儿当摆设。现在两种都能存，也照样走同一套校验
  （手打一个没带路径分隔符的串会被清空，而不是留着一条读不到的路）。

## 安装与首次使用

1. 下载 `大肥鱼-1.3.0-安装包.exe`，核对 SHA-256：
   `4CCEC97F435BBBB18171B1C8C5A9419AE2A740F7ECC2EE768958FB393A8E1D2D`
2. 没有代码签名，SmartScreen 会提示「未知发布者」：点「更多信息 → 仍要运行」。
3. 安装包**不含模型**（版权在原画师手上）。第一次打开是欢迎卡和「先给她找一个身体」，
   按提示导入自己的 Live2D 模型压缩包（zip）或解压后的文件夹。
4. 存档在 `%APPDATA%\dafeiyu-desk`，覆盖安装会保留；卸载默认不删。
5. 从旧版升级可以直接装，不必先卸载旧版：装到同一个目录会用新文件覆盖旧的，
   存档、模型、导入的语音都留着。慢一点的机器上这一步要等一两分钟
   （1.9 GB 要重新解开），窗口不动是在解包，不是卡死。
6. 装进**中文目录没问题**（`D:\软件\大肥鱼` 验过）。但如果用 `安装包.exe /S /D=路径`
   静默部署，**路径里不要带空格**：NSIS 的 `/D=` 会在第一个空格处截断，而且安装器
   仍然返回成功 —— 看起来装完了，其实装到了空格前面那一层。图形界面安装没有这个限制。

## 已知限制

- 未签名，SmartScreen 会提示；每个包的 SHA-256 以 Release 说明为准。
- 检查更新依赖 `api.github.com`，网络不通时只提示失败，不影响桌宠。
- 内置「看屏幕」需要本机 DSH 手机桥接在跑；外部视觉接口会把截图发到你自己填的服务。
- 用读屏时建议 `Ctrl+Shift+M` 静音角色语音，否则同一句会被念两遍。
- 只在 Win10/11 x64 上验证过；ARM64 与精简版系统未测。
- 极少数机器上，安装器写文件阶段可能异常退出（`0xC0000005`，界面表现为安装窗口闪退）。重跑一次安装包即可；反复出现时把目录换成纯英文路径。
