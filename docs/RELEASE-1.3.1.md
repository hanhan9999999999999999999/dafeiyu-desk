# 大肥鱼 1.3.1

2026-11-15 · Windows 10 / 11 x64 · 930,192,253（约 887.1 MB）

这一版接着 1.3.0 往下打磨：把她「出错时一声不吭」的地方逐个补上人话，把只在真机上才暴露的
几条边界（掉线、锁屏、换模型、装到中文目录）钉进自检，并且第一次让「不收集、不上传」
「删得干净」这类承诺可以被机器验证。

## 修复

- **桥断了，她还在一脸思考。** 与 DSH 的连接断掉之后，状态一直停在「她在想」，表情僵住、
  也不再主动说话。现在连续两次探测失败（约 16 秒）才判定断开，断开时她会说一句
  「我这边连不上 DSH 了……」，重连后说「连上了，我在。」；短暂的网络抖动不会被当成断线。
- **两个来源互相抹掉「她在忙」。** 主进程每 2 秒看一次 DSH 会话文件，手机桥每 8 秒报一次忙闲，
  以前两边各写一次状态、谁最后写谁赢，于是桥说她忙、脸上却是闲的。现在两边取并集。
- **麦克风开不起来时她什么都不说。** 权限被拒、没有设备、被别的程序占用、设备不支持、
  页面不安全、被中断、说到一半掉线 —— 七种情况各有各的人话，还都写了下一步该动哪里
  （Windows 设置 → 隐私和安全性 → 麦克风 ⋯）。设置页的麦克风下拉也终于会解释自己为什么是空的。
- **她说不出来的时候一声不吭。** 语音有五级降级链（飞鱼流式 → 分段流式 → 换音色 → 内置引擎 →
  DSH 桥接），以前全挂只写一行日志、正文照弹、界面安静。现在会按「最具体的那一档」说清楚，
  例如「本地语音引擎没起来，我说不出话」，并且不会把 `HTTP 503` 这种原文甩给用户。
- **等她回复超时的时候，界面什么都不说。** 只来了半截 → 「……好像没说完（等了 N 秒）」；
  一个字都没回来 → 「她还没回我……要不再说一次？」；连基线都读不到时，只认最近一分钟的消息，
  不会把五分钟前的旧话当成她刚说的念出来。
- **对话记录读不懂的时候，程序会把它当空的，然后覆盖掉。** 现在把原文件留成
  `chatlog.json.bad-<时间戳>`，日志里记一笔，然后当成空记录继续跑；脏数据会如实报数，
  超过上限只丢最旧的。
- **设置里的开关，手快连点第二下会被吞掉。** 界面先乐观翻转，写盘失败再拉回真实状态。
- **同一个按键分给两个功能时，界面说两个都生效。** 现在会明确写「和另一个功能用了同一个键，
  只生效了一个」。
- **关掉「总在最前」之后，按一次唤出就永久置顶。** 唤出现在尊重这个开关。
- **改一下取景，16 MB 的模型要重新解析一遍。** 「换模型」与「换规则」拆成两条通路，
  改取景不再整页重载（实测页面加载次数 1 → 0）。
- **升级上来之后，她站的位置变了，而且没人告诉你。** 旧版存在设置里的取景会在启动时
  搬进模型自己的配置，模型不在了就原样留着并记一条日志。
- **锁屏一整夜，程序还在每秒三十次往窗口里推鼠标坐标。** 人不在时连采样都省掉；顺带把
  「每 2 秒扫一遍会话目录」「每 8 秒打一次桥」「看屏幕」也一起停了，回来立刻补一拍。
- **每跑一次自测，`%TEMP%` 里就多一个删不掉的目录**：探针临时目录现在带 pid 标记，
  退出即删，被杀掉的下次启动顺手收。
- **设置里「参考音频目录」那个框以前存不上**（1.3.0 遗留）：只有旁边的按钮会写它，
  键盘改完按回车什么都不会发生。现在两种都能存，也照样走同一套校验。
- **她为什么没出声，重启之后就查不到了**：故障记录会落盘（最近 40 条），
  同时进诊断包，重启后还在。

## 新增

- **「清除本机数据…」**（设置 → 存储）：一次清掉对话记录、故障记录、日志、崩溃快照、
  语音缓存和几个窗口位置文件；**不动设置（含 API Key）和你自己导入的模型**，确认框里逐条写明。
- **诊断包里的「故障记录.txt」**：麦克风、说话、等回复三类失败的人话 + 原始错误。
- **引导卡会做开场体检**：缺模型 / 缺对话接口各自列一行，带「去导入」「去设置」按钮；
  只用 DSH 桥接、没填 API 地址的人不会被误报。
- **首次引导不再写真实域名示例**（避免让人以为默认会连某个服务）。

## 安装与首次使用

1. 下载 `dafeiyu-desk-setup-1.3.1.exe`，核对 SHA-256：`57FE5B5AA3C0ADEC2077FE479955EFB0E40C416D3481D65E1DA62475D2481A4C`
2. 没有代码签名，SmartScreen 会提示「未知发布者」：点「更多信息 → 仍要运行」。
3. 安装包**不含模型**（版权在原画师手上）。第一次打开是欢迎卡，按提示导入你自己的
   Live2D 模型压缩包（zip）或解压后的文件夹。
4. 存档在 `%APPDATA%\dafeiyu-desk`，覆盖安装会保留；卸载默认不删。
5. 从 1.3.0 升级可以直接装，不必先卸载：存档、模型、导入的语音都留着。
6. 装进**中文目录没问题**（`D:\软件\大肥鱼` 验过）。但用 `/S /D=路径` 静默部署时，
   **路径里不要带空格**：NSIS 的 `/D=` 会在第一个空格处截断，而且安装器仍然返回成功。

## 已知限制

- 未签名，SmartScreen 会提示；每个包的 SHA-256 以 Release 说明为准。
- 检查更新依赖 `api.github.com`，网络不通时只提示失败，不影响桌宠。
- 内置「看屏幕」需要本机 DSH 手机桥接在跑；外部视觉接口会把截图发到你自己填的服务。
- 用读屏时建议 `Ctrl+Shift+M` 静音角色语音，否则同一句会被念两遍。
- 只在 Win10/11 x64 上验证过；ARM64 与精简版系统未测。
- 极少数机器上，安装器写文件阶段可能异常退出（`0xC0000005`，表现为安装窗口闪退）。
  重跑一次安装包即可；反复出现时把目录换成纯英文路径。
