大肥鱼 · 隐私说明
最后更新：2026-11-10

一句话：这个软件不收集、不上传任何使用数据。日志、缓存、录音、截图都留在你自己的电脑里。


一、它不会做什么

- 不收集设备信息、使用统计、崩溃上报。crashReporter 是开着的，但 uploadToServer: false，崩溃只写本地文件。
- 不上传日志、设置、诊断包。诊断包必须你自己点「导出」，并且由你选目录。
- 不读与功能无关的文件。
- 不向任何第三方分析平台发送数据。
- 没有账号系统，不需要登录，也没有遥测开关（因为它本来就不发）。


二、会联网的地方（只有这几处）

1. 对话 / 看屏幕
   你发的消息会发给你自己配置的模型服务。默认是 https://api.deepseek.com，可以在「设置 → 回复模型」里改成任何兼容 OpenAI 协议的地址。
   内容只发给你填的那一个地址。API Key 存在本机的 settings.json 里，不经过我们。

2. 语音识别模型下载
   第一次用语音输入时，会从 https://hf-mirror.com 下载 whisper turbo 模型（约 1.6G）。
   只下载模型文件，不上传任何内容。设置页可以随时暂停 / 继续，也可以换成你自己的下载地址。

3. DSH 桥接（手机通道 / 看屏幕）
   连的是你自己填的桥接地址，默认 127.0.0.1。换成局域网里另一台电脑时，数据直接在那两台机器之间走。

4. 本地语音服务
   飞鱼 / RVC / XTTS 默认都跑在 127.0.0.1，合成的音频不离开本机。


三、本地会存什么，存在哪

- 设置：userData\settings.json（包含 API Key，明文——这是本机配置文件，不是云端存储）
- 日志：userData\run.log（轮转，单个文件 2MB 上限）
- 崩溃记录：userData\crash\（最多保留 20 份）
- 语音缓存：userData\runtime\tts\（可在设置里清空，也可以换盘）
- 识别模型：userData\models\（约 1.6G，删了下次会自动重下）
- 聊天记录、截图：userData 下对应的文件

userData 的默认位置是 %APPDATA%\dafeiyu-desk。装了多个用户的话，每个用户一份。


四、怎么删

- 语音缓存：设置 → 存储 → 清空缓存
- 全部数据：退出软件，删掉 %APPDATA%\dafeiyu-desk
- 卸载程序本身不会删 userData——你的设置和聊天记录会保留。要彻底清除，按上一条手动删。
