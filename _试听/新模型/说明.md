# 六个新 RVC 模型试听

同一句话，同一段晓萱原声输入：

> 这是常识，不要尝试在这时候吃柿子，知道吗。

「常/识/尝/试/时/候/吃/柿/子/知/道」全挤在一起——翘舌 zh/ch/sh 和平舌 z/c/s 连着出现，卷不卷一句话就听出来。

## 客观指标（跟晓萱原声放一起）

```
              质心Hz   >4kHz%   平坦度
晓萱原声       3083    31.33    0.4529
雅琳御姐       2404    23.72    0.4328   ← 最低，胸腔共鸣重，御姐味
诗韵           2968    29.80    0.5158   ← 质心最靠近原声
婉心           3273    32.96    0.5924   ← 平衡
北极星         3699    39.33    0.6210
草莓           3868    40.20    0.6559   ← 甜
学姐           4273    46.69    0.6821   ← 最亮
```

**别只看数字。** 质心低不等于闷——雅琳御姐 2404 是胸腔共鸣撑起来的，草莓 3868 是甜的亮，两种都不是「坏」。

**真正要听的只有一件事：翘舌音清不清楚。**「常识」会不会变成「藏识」，「尝试」会不会变成「蚕式」。

## 怎么换上

设置 → 语音输出 → RVC → 模型路径填：

```
models/yalin/yalin.onnx        雅琳御姐
models/caomei/caomei.onnx      草莓
models/wanxin/wanxin.onnx      婉心
models/beijixing/beijixing.onnx 北极星
models/shiyun/shiyun.onnx      诗韵
models/xuejie/xuejie.onnx      学姐
```

**注意前面要带 `models/`**——相对路径是相对 `_app/rvc/` 算的，漏了这一级会报「找不到模型」。

## 一句话总结现状

RVC 这条线我能做的都做了：参数扫过、采样率查过、六个新模型下好。**但中文翘舌音这件事，八成还是会卷**——不是模型不好，是 ContentVec 把 16kHz 的语音压成每秒 50 帧，zh 和 z 在这个粒度下本来就分不开。

所以还是那句话：**XTTS 那条线的 `_试听/同句对比/05-XTTS-GPU.wav` 如果音色能接受，建议走它。** 它不卷，因为它是按音素合成的，不是按特征帧还原的。
